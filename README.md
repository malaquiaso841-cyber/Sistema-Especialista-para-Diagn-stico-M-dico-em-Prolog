Sobre o Projeto

O projeto consiste no desenvolvimento de um pequeno sistema especialista
capaz de analisar sintomas informados pelo usuário e apresentar possíveis
diagnósticos com base em uma base de conhecimento desenvolvida em Prolog.

O Prolog será utilizado para representar conhecimentos por meio de fatos
e regras e realizar inferências a partir dos sintomas informados.

O Python será utilizado para realizar a interação com o usuário e,
quando tecnicamente viável, realizar a comunicação com a base de
conhecimento em Prolog.

> **Aviso:** Este sistema possui finalidade exclusivamente educacional.
> Os resultados apresentados não constituem diagnóstico médico e não
> substituem avaliação realizada por profissionais de saúde.

---

Objetivos

- Estudar os fundamentos da linguagem Prolog.
- Compreender os conceitos de programação lógica.
- Desenvolver uma base de conhecimento utilizando fatos e regras.
- Implementar um sistema especialista simples.
- Realizar inferências a partir de sintomas informados pelo usuário.
- Integrar Prolog e Python.
- Comparar a programação lógica com uma abordagem imperativa utilizando Python.
- Documentar o desenvolvimento e os resultados do projeto.
